Faceting, in one minute

A faceting keeps a polyhedron's vertices and connects them with different faces. Draw every diagonal of a pentagon and the original five vertices now bound a pentagram: the two-dimensional version.

Faceting is polar-dual to stellation. This app directly finds coplanar circuits in the chosen solid's fixed vertex table and repeats them by symmetry. Alongside that model it constructs the dual plane arrangement as a reciprocal faceting diagram. This is geometric duality, not a relabelled stellation mesh.

How to use it

  • Choose the base solid whose vertices must remain fixed.
  • The construction table exposes explicit circuit orbits. Shift adds a facet orbit; ctrl removes it. The diagram is a read-only reciprocal guide.
  • base restores the original faces. next orbit walks the directly enumerated circuit families.
  • The Great Stella button loads the dodecahedral target from the brief.
  • The F² report computes the small stellated dodecahedron as both an icosahedron faceting and a dodecahedron stellation.
  • See How it works for the exact correspondence.

Provenance

The arrangement core is a JavaScript port of the Stellation applet written by Vladimir Bulatov in 1998–2001 and checked number-for-number against the Java implementation. This mirror adds the polar-reciprocal faceting layer.

The catalog includes all 146 finite nonprismatic noble polyhedra from Connor Hill’s 2026 enumeration: nine existing regular models and 137 additions from his model library. Imported model data and derived thumbnails are provided under GPLv3, without warranty; source and conversion notes. Disphenoid and stephanoid families are not enumerated in this finite catalog.
